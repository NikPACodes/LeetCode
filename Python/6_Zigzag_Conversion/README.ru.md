<h1>6. Зигзаговое преобразование

[![ENG](https://img.shields.io/badge/README-English-red.svg)](README.md)
[![RUS](https://img.shields.io/badge/README-Russian-blue.svg)](README.ru.md)
</h1>

Строка `"PAYPALISHIRING"` пишется зигзагообразным узором в заданном количестве строк следующим образом:  
(возможно, вы захотите отобразить этот узор фиксированным шрифтом для лучшей разборчивости)

```
P   A   H   N
A P L S I I G
Y   I   R
```

А затем прочитайте строку за строкой: `"PAHNAPLSIIGYIR"`

Напишите код, который будет принимать строку и выполнять это преобразование с учетом количества строк:
```
string convert(string s, int numRows);
```
    

__Пример 1:__
```
Входные данные: s = "PAYPALISHIRING", numRows = 3
Выходные данные: "PAHNAPLSIIGYIR"
```

__Пример 2:__
```
Входные данные: s = "PAYPALISHIRING", numRows = 4
Выходные данные: "PINALSIGYAHRPI"
Пояснение:
P     I    N
A   L S  I G
Y A   H R
P     I
```

__Пример 3:__
```
Входные данные: s = "A", numRows = 1
Выходные данные: "A"
```

__Ограничения:__

- $1 <=$ `s.length` $<= 1000$  
- `s` состоит из английских букв (строчных и прописных), `','` и `'.'`.  
- $1 <=$ `numRows` $<= 1000$


<br>
<h2>Решение:</h2>

Для решения данной задачи нам достаточно пройти один раз по строке `s` и разбить её на `numRows` строк, 
а для формирования этих строк зигзагом воспользуемся флагом.  
Данное решение будет иметь линейную сложность _($$O(n)$$)_.

1) Проверим, что переданная на вход строка `s` имеет длину __большую__ чем необходимое количество строк `numRows`,  
если это __не так__, то просто __возвращаем строку__ `s` которая и будет являться решением.
    ```python
    lstr = len(s)
    if numRows == 1 or numRows >= lstr:
        return s
    ```
2) Далее создадим __список из `numRows` списков__ (`zigzag`), а также __указатель__ на список в который будем записывать значение (`zz_ind`)  
и необходимый для расчета индекса __флаг__ (`down`).
3) Циклом пройдемся по переданной на вход строке `s` и проделаем следующие шаги:
   - __Записываем__ значение в список по индексу `zz_ind`
   - Далее производим проверку нашего флага: 
     - Если индекс __равен__ $0$, то __меняем__ его на `True`. 
     - Если же индекс будет __равен__ `numRows - 1`, то __ставим__ `False`
   - Высчитываем __индекс__ для записи __следующего__ элемента:
     - Если флаг `True`, то будем записывать элемент в __следующий__ по порядку список, т.е. `zz_ind += 1`
     - В ином случае при флаге `False`, идем в обратном направлении и записываем в __предыдущий__ список, т.е. `zz_ind -= 1`
    ```python
    for i in range(lstr):
        zigzag[zz_ind].append(s[i])
        if zz_ind == 0:
            down = True
        elif zz_ind == numRows - 1:
            down = False
        zz_ind += 1 if down is True else -1
    ```
4) После прохода всей строки `s` на шаге 3, __объединяем__ все полученные списки из `zigzag` в один.
5) __Возвращаем__ получившийся список в виде __объединенной строки__ которая и будет являться решением.

### Code
```python
class Solution:
    def convert(self, s: str, numRows: int) -> str:
        lstr = len(s)
        if numRows == 1 or numRows >= lstr:
            return s

        result = list()
        zigzag = [[] for _ in range(numRows)]
        zz_ind, down = 0, True
        for i in range(lstr):
            zigzag[zz_ind].append(s[i])
            if zz_ind == 0:
                down = True
            elif zz_ind == numRows - 1:
                down = False
            zz_ind += 1 if down is True else -1

        for line in zigzag:
            result += line
        return(''.join(result))
```
