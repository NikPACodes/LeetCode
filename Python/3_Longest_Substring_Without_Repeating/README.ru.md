<h1>3. Самая длинная подстрока без повторяющихся символов

[![ENG](https://img.shields.io/badge/README-English-red.svg)](README.md)
[![RUS](https://img.shields.io/badge/README-Russian-blue.svg)](README.ru.md)
</h1>

Для заданной строки `s` найдите длину __самой длинной подстроки__ без повторяющихся символов.

__Пример 1:__
```
Входные данные: s = "abcabcbb"
Выходные данные: 3
Пояснение: Ответ — «abc», длина — 3.
```

__Пример 2:__
```
Входные данные: s = "bbbbb"
Выходные данные: 1
Пояснение: Ответ — «b», длина — 1.
```

__Пример 3:__
```
Входные данные: s = "pwwkew"
Выходные данные: 3
Пояснение: Ответ — «wke», длина — 3.
Обратите внимание, что ответ должен быть подстрокой: «pwke» — это подпоследовательность, а не подстрока.
```

__Ограничения:__
- $0 <=$ `s.length` <= $5 * 10^4$
- `s` состоит из английских букв, цифр, символов и пробелов.




<br>
<h2>Решение:</h2>

Для решения данной задачи, мы можем воспользоваться методом двух указателей.  
Первый индекс указывает на начало искомой подстроки, второй - на окончание.

1) Создадим необходимые переменные:
   - `max_len` - длинна самой длинной подстроки без повторяющихся символов
   - `check_dict` - словарь для хранения символов и их индексов в строке
   - `left` - индекс начала подстроки
2) Начинаем перебирать проиндексированную (_с помощью функции `enumerate`_) строку `s`.
3) Производим проверку:
   - Если символ строки `s` (`ch`) __находится__ в словаре `check_dict` и индекс символа __больше__ или __равен__ индексу начала строки `left`,
   то новое значение индекса начала строки `left` становится __равным__ индексу символа `check_dict[ch]` плюс $1$
   - Если в словаре `check_dict` __отсутствует__ символ строки `s` (`ch`) и длинна текущей подстроки __больше__ максимальной длинны `max_len`, 
   то __обновляем__ показатель максимальной длины подстроки.
    ```python
    if ch in check_dict and check_dict[ch] >= left:
        left = check_dict[ch] + 1
    else:
        max_len = max(max_len, right - left + 1)
    ```
4) Добавляем/обновляем запись в нашем словаре уникальных символов `check_dict`: `check_dict[ch] = right`
5) Повторяем пункты 3-4 пока не завершится строка `s`
6) Возвращаем длину самой длинной подстроки `max_len`

### Code
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        max_len = 0
        check_dict = {}
        left = 0
        for right, ch in enumerate(s):
            if ch in check_dict and check_dict[ch] >= left:
                left = check_dict[ch] + 1
            else:
                max_len = max(max_len, right - left + 1)
            check_dict[ch] = right
        return max_len
```
