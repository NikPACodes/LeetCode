<h1>50. Pow(x, n)

[![ENG](https://img.shields.io/badge/README-English-red.svg)](README.md)
[![RUS](https://img.shields.io/badge/README-Russian-blue.svg)](README.ru.md)
</h1>

Реализуйте `pow(x, n)`, которая вычисляет `x`, возведенный в степень `n` (т. е. $x^n$).

__Пример 1:__
```
Входные данные: x = 2.00000, n = 10
Выходные данные: 1024.00000
```

__Пример 2:__
```
Входные данные: x = 2.10000, n = 3
Выходные данные: 9.26100
```

__Пример 3:__
```
Входные данные: x = 2.00000, n = -2
Выходные данные: 0.25000
Пояснение: 2^(-2) = (1/2)^2 = 1/4 = 0,25
```

__Ограничения:__
- $-100.0 <$ `x` $< 100.0$
- $-2^{31} <=$ `n` $<= 2^{31}-1$
- `n` целое число.
- `x` не ноль или `n > 0`
- $-10^4 <= x^n <= 10^4$


<br>
<h2>Решение:</h2>

Для данной задачи есть 2 подхода решения:
- _с использованием цикла_
- _с использованием рекурсии_

Для решения разберем все случаи возведения числа в степень ($x^n$):
- `n < 0` => $x^{-n} = (1/x)^n$
- `n = 0` => $x^0 = 1$
- `n > 0` =>:
  - Если `n` четное, то $x^n = (x^2)^{n/2}$  
  Пример: $2^8 = (2^2)^4 = (4^2)^2 = 16^2 = 256$
  - Если `n` нечетное, то $x^n = x^{n-1}*x$  
  Пример: $2^7 = 2^6 * 2 = (2^2)^3 * 2 = 4^2 * 4 * 2 = 16 * 8 = 128$
- По условию задачи `n` является целым числом поэтому мы __не будем рассматривать__ варианты, где `n` является дробным и нам необходимо искать корень числа

### 1. Решение с использованием цикла

Решение задачи с использованием цикла:
1) Создадим переменную `dop` (_наш дополнительный множитель_) по умолчанию равную $1$
2) Проверим, является ли степень `n` __отрицательным числом или $0$__
   - При `n` __равном__ $0$, наша функция __возвращает__ $1$: `return 1`
   - В случае если `n` __отрицательное__, __заменяем__ значение `x` на `1/x` и __избавляемся от отрицательного знака__ в степени `n`
    ```python
    if n == 0:
        return 1
    elif n < 0:
        x = 1 / x
        n *= -1
    ``` 
3) Начинаем цикл для вычисления значения функции $x^n$ и дополнительного множителя `dop`.
4) Проверяем является ли `n` __нечетным__ числом:
   - Если __является__, то вычисляем дополнительный множитель, как `dop` умноженный на `x`
    ```python
    if n % 2 != 0:
        dop *= x
    ```
5) Вычисляем значения переменной `x` и показателя степени `n`:
   - значение `x` __домножается__ само на себя
   - значение `n` становится равным __целой части от деления__ `n` на $2$
6) Пункты 4-5 повторяются до тех пор, пока показатель степени `n` не __станет равным__ $1$
7) При `n` равном $1$, выходим из цикла и возвращаем получившееся значение `x` умноженное на `dop`

### Code
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        dop = 1
        if n == 0:
            return 1
        elif n < 0:
            x = 1 / x
            n *= -1
        while True:
            if n == 1:
                break
            if n % 2 != 0:
                dop *= x
            x *= x
            n //= 2
        return x * dop
```

### 2. Решения с использованием рекурсии

Решение задачи с использованием рекурсии.
Мы имеем функцию, получающую на вход значение числа `x` и число степени `n`.
1) Проверим, является ли степень __отрицательным числом или $0$__
   - Если `n` __равно__ $0$, то функция __возвращает__ $1$: `return 1`
   - Если `n` __меньше__ $0$, то __заменяем__ значение `x` на `1/x` и __избавляемся от отрицательного знака__ в степени `n`
    ```python
    if n == 0:
        return 1
    elif n < 0:
        x = 1/x
        n *= -1
    ```
2) При значении `n` __больше__ $0$, производим вторую проверку:
   - Если `n` является __четным__ числом (т.е. `n % 2 == 0`), 
   то функция возвращает __саму себя__ со следующими параметрами: 
     1. параметр `x`: передается __квадрат числа__ `x`  
     2. параметр `n`: передается __целая часть от деления__ `n` на $2$
   ```python
   return self.myPow(x * x, n // 2)
   ```
   - В случае, если `n` является __нечетным__ числом (т.е. `n % 2 != 0`), 
   то функция возвращает __саму себя__ (с аналогичными параметрами, что и с четным значением) __домноженную__ на `x`: 
   ```python
   return self.myPow(x * x, n // 2) * x
   ```
3) Рекурсия повторяется до тех пор, пока `n` не __станет равным__ $0$

### Code
```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n == 0:
            return 1
        elif n < 0:
             x = 1/x
             n *= -1
        if n % 2 == 0:
            return self.myPow(x * x, n // 2)
        else:
            return self.myPow(x * x, n // 2) * x
```
