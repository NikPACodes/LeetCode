<h1>14. Самый длинный общий префикс

[![ENG](https://img.shields.io/badge/README-English-red.svg)](README.md)
[![RUS](https://img.shields.io/badge/README-Russian-blue.svg)](README.ru.md)
</h1>

Напишите функцию для поиска самой длинной общей строки-префикса среди массива строк.
Если общего префикса нет, верните пустую строку `""`.

__Пример 1:__
```
Входные данные: strs = ["flower","flow","flight"]
Выходные данные: "fl"
```

__Пример 2:__
```
Входные данные: strs = ["dog","racecar","car"]
Выходные данные: ""
Пояснение: Среди входных строк нет общего префикса.
```

__Ограничения:__
- $1 <=$ `strs.length` $<= 200$
- $0 <=$ `strs[i].length` $<= 200$
- `strs[i]` состоит только из строчных английских букв, если он не пуст.


<br>
<h2>Решение:</h2>

1) Создадим переменные `pref` (_для хранения префикса_) и `len_pref` (_длинна префикса_)
2) Начнем перебор принятого на вход массива строк `strs`.
3) Для первого элемента массива `strs[0]`:
   - в переменную `pref` записываем всю строку `v_str` (`strs[0]`)
   - в переменную `len_pref` записываем длину строки
    ```python
    if i == 0:
        pref, len_pref = v_str, len(v_str)
    ```
4) Для всех последующих элементов проводим проверку:
   1. Если длинна текущей строки __меньше__ значения переменной `len_pref`, то:
     - обновляем значение `len_pref`: `len_pref` равна длине __текущей__ строки
     - обновляем значение `pref`: `pref` __сокращается__ до длинны `len_pref`
     ```python
     if len_pref > len(v_str):
        len_pref = len(v_str)
        pref = pref[:len_pref]
     ```
   2. В цикле проверяем соответствует ли префикс текущей строки искомому префиксу. 
5) Проверка соответствия текущего префикса искомому:
   - Если префикс текущей строки __соответствует__ искомому префиксу, мы __переходим на следующий элемент__ массива строк `strs`
   - Если префикс __несоответствует__, то: 
     1. __уменьшаем длину__ искомого префикса `len_pref` на $1$
     2. __сокращаем__ искомый префикс `pref` на один символ
    ```python
    if v_str[:len_pref] == pref:
        break
    else:
        len_pref -= 1
        pref = pref[:len_pref]
    ```
6) Пункты 4-5 повторяются до тех пор, пока не __закончится__ список строк `strs`, либо длина искомого префикса `len_pref` не __уменьшится до $0$__
7) Возвращаем оставшийся префикс `pref`, являющийся решением нашей функции.
