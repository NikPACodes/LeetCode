<h1>2. Сумма двух чисел

[![ENG](https://img.shields.io/badge/README-English-red.svg)](README.md)
[![RUS](https://img.shields.io/badge/README-Russian-blue.svg)](README.ru.md)
</h1>

Вам даны два __непустых__ связных списка, представляющих два неотрицательных целых числа.
Цифры хранятся в __обратном порядке__, и каждый из узлов списков содержит только одну цифру.
Сложите два данных числа и верните обратно сумму в виде связного списка.  
Можно предположить, что числа не содержат ведущих нулей, кроме самого числа 0.

__Пример 1:__

![ex1](https://assets.leetcode.com/uploads/2020/10/02/addtwonumber1.jpg)

```
Входные данные: l1 = [2,4,3], l2 = [5,6,4]
Выходные данные: [7,0,8]
Пояснение: 342 + 465 = 807.
```

__Пример 2:__
```
Входные данные: l1 = [0], l2 = [0]
Выходные данные: [0]
```

__Пример 3:__
```
Входные данные: l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
Выходные данные: [8,9,9,9,0,0,0,1]
```

__Ограничения:__
- _Число узлов в каждом связном списке находится в диапазоне [1, 100]_.
- `0 <= Node.val <= 9`
- _Гарантируется, что список представляет собой число, не имеющее начальных нулей_.




<br>
<h2>Решение:</h2>

Для решения данной задачи необходимо пройти по всем значениям переданных списков `l1`, `l2` и просуммировать их значение в результирующий связный список. 
Так как значение списка может принимать только единичный разряд, заведем переменную для дополнительного хранения десятичного разряда.

1) Инициализируем __узел__ связного списка и __ссылку__ на это узел (_первый узел нашего списка_):  
   ```
   result = ListNode()
   result_first = result
   ```
2) Создаем переменную `intDiv` для хранения __десятичных разрядов__ при расчете т.к., по условию значение узла _может принимать только единичный разряд_.
3) Для расчета суммы узлов двух списков инициализируем переменную `sumLists` по умолчанию равную `intDiv` (_для переноса десятичного разряда при переходе на следующий узел_)
4) Начинаем перебор и проверку переданных на вход связных списков `l1` и `l2`:  
   - Если узел `l1` __инициализирован__ (`l1 != None`), то __добавляем__ значение узла к `sumLists` и __переходим__ на следующий узел списка `l1.next`:
   ```python
   if l1:
        sumLists += l1.val
        l1 = l1.next
   ```
   - Аналогично поступаем с узлом `l2`:
   ```python
   if l2:
        sumLists += l2.val
        l2 = l2.next
   ```
5) Заносим __единичный разряд__ значения `sumLists` в узел нашего списка `result`, а __десятичный разряд__ в переменную `intDiv`:
   ```python
    result.val = sumLists % 10
    intDiv = sumLists // 10
   ```
6) Производим проверку:
   - Если у нас __инициализирован__ узел `l1`, либо `l2`, либо `intDiv` не равен `0`, то __инициализируем__ следующий элемент нашего списка `result` и __переходим__ на него.
   - Иначе, __выходим__ из цикла.
   ```python
    if l1 or l2 or intDiv:
        result.next = ListNode()
        result = result.next
    else:
        break
    ```
7) _Повторяем пункты 3-6_ до тех пор, пока не __закончатся__ переданные на вход списки (т.е. `l1 = None` и `l2 = None`) и __не останется__ десятичного разряда (т.е. `intDiv = 0`)
8) Возвращаем `result_first` - __узел первого элемента__ нашего итогового связного списка.


### Code
```python
from typing import Optional

class ListNode(object):
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
        
class Solution(object):
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode])->Optional[ListNode]:
        result = ListNode()
        result_first = result
        intDiv = 0
        while True:
            sumLists = intDiv
            if l1:
                sumLists += l1.val
                l1 = l1.next
            if l2:
                sumLists += l2.val
                l2 = l2.next

            result.val = sumLists % 10
            intDiv = sumLists // 10
            if l1 or l2 or intDiv:
                result.next = ListNode()
                result = result.next
            else:
                break
        return result_first
```
