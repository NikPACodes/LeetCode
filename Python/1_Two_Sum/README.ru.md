<h1>1. Сумма двух чисел

[![ENG](https://img.shields.io/badge/README-English-red.svg)](README.md)
[![RUS](https://img.shields.io/badge/README-Russian-blue.svg)](README.ru.md)
</h1>

Дан массив целых чисел `nums` и целочисленное значение `target`, вернуть _индексы двух чисел так, чтобы их сумма равнялась_ `target`.  
Можно предположить, что каждое входное значение имеет __ровно одно решение__, and и нельзя использовать _один и тот же_ элемент дважды.  
Ответ можно возвращать в любом порядке.

__Пример 1:__
```
Входные данные: nums = [2,7,11,15], target = 9
Выходные данные: [0,1]
Пояснение: Поскольку nums[0] + nums[1] == 9, мы возвращаем [0, 1].
```

__Пример 2:__
```
Входные данные: nums = [3,2,4], target = 6
Выходные данные: [1,2]
```

__Пример 3:__
```
Входные данные: nums = [3,3], target = 6
Выходные данные: [0,1]
```

__Ограничения:__
- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`

- __Существует только один правильный ответ.__

 
__Дополнение:__ Можете ли вы предложить алгоритм, временная сложность которого меньше `O(n^2)`?  

<br>
<h2>Решение:</h2>


### 1. Решение в лоб *(сложность `O(n^2)`)*

Решение в лоб:  
1) Циклом пройдемся по каждому элементу списка `nums`
2) Вложенным циклом проверяем существует ли в оставшихся элементах пара, в сумме с текушим элементом списка равная `target`
   - Если пара __найдена__, _возвращаем соответствующую пару индексов_ `return [i, j]`
3) В случае если подходящей пары __не нашлось__, _возвращаем пустое множество_ `return []`
### Code
```python
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        n = len(nums)
        for i in range(n - 1):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []
```
<br>

### 2. Решения с использованием Хэш-таблицы *(сложность `O(n)`)*

Решение с использованием хэш-таблицы (через словарь):  
   1) Создадим словарь `numsCheck = {}` выполняющий роль нашей _хэш-таблицы_
   2) В цикле проверяем полученный на вход _проиндексированный_ (с помощью функции `enumerate`) список.
   3) Производим проверку каждого элемента цикла на наличие в нашей хэш-таблице:
      - Если элемент _отсутствует_, то добавляем в `numsCheck` запись: `numsCheck[num_diff] = i`  
        где __ключом__ - является _разность между искомым значением и значением текущего элемента массива_ `num_diff = target - num`,  
        а __значением__ - _индекс текущего элемента массива_
      - Если элемент _присутствует_ в `numsCheck`, то возвращаем пару индексов которые и будут являться решением:  
        `return [numsCheck[num], i]`  
        где `i` - _индекс текшего элемента_,  
        а `numsCheck[num]` - _индекс элемента в сумме дающий искомый_ `target`  
        Т.е. **`nums[numsCheck[num]] + nums[i] = target`**
   4) В случае если подходящей пары __не нашлось__, _возвращаем пустое множество_ `return []`
### Code
```python
class Solution(object):
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        numsCheck = {}
        for i, num in enumerate(nums):
            num_diff = target - num
            if num in numsCheck:
                return [numsCheck[num], i]
            numsCheck[num_diff] = i
        return []
```
